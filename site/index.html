What it does

A chat on one side, a real terminal on the other, and you stay in control of every command.

Plain English to commands

Describe a task and get a shell command with an explanation. Nothing runs until you click Run.

Guest mode

No server? Open a terminal on your own machine (macOS and Linux) with one click.

SSH to servers

Connect with a password or key, and save reusable connection profiles.

Troubleshooting

Paste an error and get step-by-step diagnosis: checks to run, then a suggested fix.

Jenkins log analysis

Point it at a failed build's console log and get the likely cause and fix.

System-aware

Detects the OS and installed tools, so suggestions fit the machine you're on.

Get started

You need Python 3.9 or newer and git. It takes about two minutes.

  1. Get the code 
    git clone https://github.com/Anurag-5ingh/OpsPilot.git
cd OpsPilot
  2. Install (on Windows, activate with .venv\Scripts\activate) 
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  3. Add an AI key (optional: the terminals work without one) 
    cp .env.example .env
# then set OPENAI_API_KEY in .env
  4. Run, then open http://127.0.0.1:8080/opspilot 
    python app.py

Full instructions, including Windows and other AI providers: Setup guide.

Runs on your machine

Why the live demo is simulated.

OpsPilot executes shell commands, so it's meant to run locally. By default it listens only on 127.0.0.1, and guest mode is only offered to browsers on the same machine.

Don't expose it to the internet. It has no login of its own.
